# Lucene-style Query DSL over liqe

We chose a typed Lucene-style Query DSL (dot-path field clauses, wildcards, quoted values, AND/OR/NOT, parentheses, ordering comparisons) instead of plain text search or AG Grid's built-in column filters as the primary way to select Records, because the tool's core job is ad-hoc querying of arbitrary JSON shapes — nested fields included. The grammar is parsed and evaluated with the [`liqe`](https://github.com/gnavli/liqe) library (actively maintained, TypeScript-native, parses and evaluates); two deviations are accepted and documented in the UI, linked to liqe's docs: quoted values mean case-sensitive *substring* match (exact match via regex literal), and `!=` is absent from liqe's grammar, so it is supported by a shim over liqe's AST. AG Grid's native column filters remain enabled alongside the DSL (see ADR-0002 composition), but the DSL is the *primary* surface.
